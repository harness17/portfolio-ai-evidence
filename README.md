# Software Development Portfolio

A public one-page software development portfolio for job-hunting and interview use. It leads with about nine years of professional web development (work episodes in a 課題 / 判断 / 結果 format), then the technical stack and shipped personal products as evidence. AI-assisted workflow is one supporting section.

This repository contains only public portfolio assets:

- `index.html`
- `assets/styles.css`
- `assets/ai-workflow-codex-claudecode.webp` (workflow diagram, also used as the link preview image)
- `CLAUDE.md`
- `AGENTS.md`
- `CLAUDE_CODE_HANDOFF.md`

Private job-search documents, application tracking, email analysis, health details, and contact details are intentionally excluded.
